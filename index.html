Inspector

销售易数据工作台

隐私说明

发布者：Amos Tang（唐杰海）
更新日期：2026 年 10 月 12 日 · 适用版本：0.5.2

Inspector 是适用于销售易的独立第三方浏览器扩展，用于在你授权的环境中查询对象、字段和数据，以及通过明确确认导入或删除记录。本产品不属于销售易官方产品，未获得销售易的官方背书或认证。

1. 处理的数据及用途

  • 当前页面地址：仅在你主动点击插件工具栏图标时读取该标签页 URL，用于识别服务器地址。保存协议、主机、端口及已配置的部署前缀，不保存原页面查询参数和片段，不读取浏览历史列表或其他标签页。
  • 连接及认证信息：处理你配置的服务器地址、API 路径、Access Token 和附加请求头。使用浏览器会话认证时，由浏览器按 Cookie 规则向指定服务器发送适用的 Cookie；本扩展不使用 Cookie 管理接口读取 Cookie 列表。
  • SQL 与元数据：处理 SQL 文本、对象和字段描述、查询历史和收藏，用于查询、补全、筛选与恢复工作。
  • 业务记录：处理查询返回的字段、记录 ID 和内容，以及你选择的 Excel 文件与列映射。内容可能包含个人信息或企业机密，具体取决于你查询和导入的数据。
  • 操作报告：保留当前标签页的最近一次导入或删除计划及逐条结果，用于确认操作范围、查看结果和避免重复提交。

2. 数据流向

查询、元数据和写入请求仅发送到你授权并配置的服务器。Excel 文件在浏览器本地解析，只有你确认导入的字段值会提交到目标服务器；不会上传整个 Excel 文件。删除仅在你明确确认后向目标服务器发送所选记录 ID。

本扩展不向作者运营的服务器、广告网络、分析平台或 AI 服务发送业务数据、SQL、认证信息和文件；不出售数据，不投放广告，不进行遥测或用户画像。运行时不从远程下载可执行代码或字体。你配置的服务器及浏览器本身的数据处理遵循其各自的政策。

3. 保存位置和期限

  • 服务器配置、按连接区分的 SQL 草稿、最多 50 条成功查询历史和最多 100 条收藏保存在本机扩展存储，不使用浏览器账号同步。SQL 条件可能包含业务信息。
  • Token 和附加请求头保存在浏览器会话存储。浏览器会话结束、扩展重新加载、禁用或更新后需重新填写。
  • 查询记录主要保留在当前页面内存中。删除所需的 SQL、对象和 ID 快照，以及每个标签页最近一次写入计划、导入字段值和逐条报告暂存在浏览器会话存储中。快照与预览的操作有效期为 15 分钟，失效不代表立即从存储擦除；后续操作可覆盖，浏览器会话或扩展生命周期结束时清除。
  • 分隔条尺寸保存在本地页面存储。手动导出的 CSV、JSON 和操作报告由浏览器保存到你选择的位置，不会因卸载扩展而删除。

4. 你的选择

你可以拒绝服务器访问授权、在浏览器扩展设置中撤销主机权限、清空查询历史或逐条删除收藏、取消写入预览。取消预览不会提交写入；已确认且已发出的操作不能通过关闭页面撤回。

卸载扩展可清除它的本地扩展数据；浏览器会话数据按浏览器规则清除。自行删除导出文件。插件无法清除目标服务器上的业务记录、审计日志或由管理员保留的数据，需联系你们的系统管理员。

5. 安全与权限

扩展仅声明 storage 和 activeTab 权限，并按你的操作申请特定主机访问权限。可选主机范围用于兼容不同 SaaS 和私有化地址，不代表安装后自动访问所有网站。请求不会自动跟随认证跳转或绕过证书校验。

请使用 HTTPS 和具有适当权限的账号。此版本保留内网 HTTP 兼容；HTTP 不加密网络传输，不能当作 HTTPS 的替代。扩展本地存储未额外实施应用层加密，应保护浏览器配置和设备访问。作者不能保证目标服务器安全、接口兼容性或误操作后的恢复。

6. 数据使用限制

Inspector 对从浏览器或用户获得的数据的使用仅限于本说明列明的用户可见功能，并遵循 Chrome Web Store User Data Policy，包括 Limited Use 要求。不用于广告、数据经纪、信用判断或与本工具无关的目的。
